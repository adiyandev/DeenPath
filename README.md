# DeenPath

A mobile application project focused on creating a useful, calm, and accessible Islamic companion experience.

## 🎯 Vision

DeenPath explores a mobile-first experience for Muslims with an emphasis on practical features, clean navigation, and an ad-free product philosophy.

## ✨ Project Direction

- 📱 Cross-platform mobile experience
- 🕌 Islamic-focused utilities and content
- 🧭 Simple, focused navigation
- 🎨 Modern mobile UI
- 🚫 No advertising as a core product direction

## 🛠️ Technology

The project is built with **React Native** and **TypeScript**.

## 🚧 Status

DeenPath is an active personal project. Features and implementation may change during development.
